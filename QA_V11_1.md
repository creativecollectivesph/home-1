# V11.1 targeted QA (14 October 2026)

- **Four workspaces:** Management, Talent, Client, HR tested with **isolated, mocked authenticated test records**, on 1440px desktop and 390px mobile (8 route/viewport combinations). All screens rendered with no uncaught JavaScript errors or page-width overflow.
- **Theme:** light → dark → light worked on all eight screens, including dynamic icon changes and accessible button labels.
- **Animated background:** shared website contour canvas included on all four role pages; role-specific CSS gradients and rings displayed. Headless browser used a no-GPU fallback; **actual WebGL performance still requires device testing**.
- **Unified login:** toggle light → dark → light passed both standard and `prefers-reduced-motion: reduce` scenarios.
- **Source:** Node syntax checks passed for core/app/login/contour JS. Static portal asset references exist.
- **Not tested:** production Supabase authorization, login with actual users, hosted synchronization, or animation smoothness on real mobile GPUs. Supabase `tjc-portal` project was inactive as of the prior verification; this UI update does not change that.
- **No functional workflows removed:** changes confined to theme handling, portal canvas/layout layers, and shared front-end loading; task, clock-in/out, job publishing, messaging and database schema are unchanged.
